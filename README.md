# AgriExport AI

Commercial agricultural export intelligence for Indian exporters, with a FastAPI backend and Next.js dashboard.

The application lives in [`agriexport-ai/`](agriexport-ai/). Start with the [setup and run instructions](agriexport-ai/README.md), [implementation status](agriexport-ai/STATUS.md), and [truck guide documentation](agriexport-ai/docs/TRUCK_GUIDE.md).

This is a research pilot. No validated live export recommendation, current legal approval, or realised profit is claimed. Local datasets, secrets, dependencies and generated build artifacts are excluded from this repository.
