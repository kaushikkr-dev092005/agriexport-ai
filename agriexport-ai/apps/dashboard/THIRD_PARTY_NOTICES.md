# UI and reference asset attribution

Aceternity UI components by Manu Arora are included as end-product components from
the official public registry: Bento Grid, Hover Border Gradient and Text Generate
Effect. Exact source URLs and response checksums are in `aceternity-sources.json`.
Source files live under `components/ui/`; adaptations include link typing, reduced
motion, and application typography. See https://ui.aceternity.com/licence . No paid
template has been acquired or represented as owned. These components are integrated
into this application, not offered as a competing component library or template.

Natural Earth reference geography is public domain. Its source URL, terms and
checksum are in `public/map-source.json`. Geography is not market evidence.

Original decorative landscape artwork is AI-generated using the built-in image
generation tool. Its generation prompt is recorded in `ARTWORK.md`; it is not
documentary farm imagery, trade data or forecast evidence.

Design direction references https://officecommun.com/projects/figr : warm neutrals,
editorial type, generous spacing and landscape imagery. No Figr copy, logos,
proprietary artwork or website source have been incorporated.
